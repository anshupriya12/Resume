# Resume Repository

This project contains the resume of Anshu Priya in both editable and printable formats.

## Files

- `main.md` — the source resume in Markdown
- `_Anshu_Priya_resume_.pdf` — PDF version of the resume

## Purpose

The repository is meant to keep a clean, version-controlled copy of the resume that can be:

- edited easily in Markdown
- exported to PDF when needed
- shared with recruiters, internships, and hiring teams

## Quick usage

1. Open `main.md` in a Markdown editor or VS Code.
2. Update the content as needed.
3. Export or convert it to PDF for submission.
